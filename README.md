# منصة تقييم التعليم الأخضر

منصة لتقييم المؤسسات التعليمية ضمن مبادرة التعليم الأخضر — وزارة التربية والتعليم، مملكة البحرين. تغطي **378
مؤسسة** موزّعة على **ستة فرق تقييم**، ببناء Deno + Deno KV وواجهة عربية RTL.

## الأدوار والصلاحيات

الصلاحيات **مطبَّقة في الخادم** لا في المتصفح؛ كل طلب يُفحص قبل تنفيذه.

| الشاشة                      | عضو التقييم | رئيس الفريق  | الحساب الفني |
| --------------------------- | ----------- | ------------ | ------------ |
| مؤسساتي وإدخال التقييم      | مؤسساته فقط | —            | —            |
| لوحة الفريق                 | —           | فريقه        | كل الفرق     |
| الإحصاءات                   | مؤسساته     | فريقه        | وطنية        |
| أعلى 10 واختيار قصص النجاح  | —           | فريقه (حد 3) | كل الفرق     |
| التقارير والتصدير           | —           | فريقه        | وطنية        |
| إدارة الحسابات وسجل التدقيق | —           | —            | كامل         |

قواعد إضافية مفروضة في الخادم:

- المقيّم لا يحفظ تقييماً لمؤسسة ليست ضمن مؤسساته.
- رئيس الفريق لا يُدخل تقييمات، ولا يختار من خارج فريقه.
- الاختيار لقصص النجاح **من أعلى 10 فقط**، وبحد أقصى **3 مؤسسات لكل فريق**.
- لا تُكتب قصة نجاح لمؤسسة غير مختارة، وإلغاء الاختيار يحذف قصتها.
- كل دخول وحفظ وتعديل يُسجَّل في سجل التدقيق.

## طريقة الحساب

نقاط المحور = وزن المحور × نسبة التنفيذ. نتيجة المؤسسة = مجموع النقاط ÷ السقف.

|               | التعليم النظامي          | رياض الأطفال             |
| ------------- | ------------------------ | ------------------------ |
| السقف         | 5,400                    | 4,500                    |
| أوزان المحاور | 1500 / 1800 / 1500 / 600 | 1400 / 1400 / 1100 / 600 |

**المسطرة المعتمدة:** غير مستدام 0–65 · قيد الاستدامة 66–76 · مستدام جزئياً 77–89 · مستدام 90–100.

## النشر من المتصفح (بلا أوامر)

راجع **`دليل_النشر_من_المتصفح.md`** — خطوات مصوّرة بالكلمات من إنشاء المستودع إلى الرابط النهائي.

## التشغيل محلياً (اختياري)

```bash
# 1) ثبّت Deno
curl -fsSL https://deno.land/install.sh | sh

# 2) شغّل
SEED_PASSWORD='كلمة-مرور-قوية' deno task start
```

ثم افتح <http://localhost:8000>.

عند أول تشغيل تُنشأ الحسابات الـ37 والمؤسسات الـ378 تلقائياً، وتكون كلمة المرور الابتدائية لكل الحسابات هي قيمة
`SEED_PASSWORD`. **كل حساب يُطالَب بتغييرها عند أول دخول.**

إن لم تُضبط `SEED_PASSWORD` تُولَّد كلمة عشوائية وتُطبع في سجل التشغيل مرة واحدة.

### الأوامر

| الأمر             | الغرض                           |
| ----------------- | ------------------------------- |
| `deno task dev`   | تشغيل مع إعادة التحميل التلقائي |
| `deno task start` | تشغيل عادي                      |
| `deno task check` | التحقق من الأنواع               |
| `deno task fmt`   | تنسيق الشيفرة                   |
| `deno task lint`  | التدقيق                         |

### الاختبارات

```bash
# نافذة أولى
SEED_PASSWORD=Test#2026 KV_PATH=/tmp/t.db deno task start
# نافذة ثانية
SEED_PASSWORD=Test#2026 BASE=http://127.0.0.1:8000 deno run --allow-net --allow-env tests/api_test.ts
```

الاختبارات تغطي: المصادقة · نطاق كل دور · منع تعديل مؤسسات الغير · تقييد القيم بين 0 و100 · حد الثلاث قصص · منع
الاختيار خارج أعلى 10 · تغيير كلمة المرور · سجل التدقيق · انتهاء الجلسة · ومنع الخروج من مجلد الملفات الثابتة.

## النشر على Deno Deploy

1. ارفع المستودع إلى GitHub.
2. من <https://dash.deno.com> أنشئ مشروعاً جديداً واربطه بالمستودع.
3. اضبط نقطة الدخول على `main.ts` والفرع على `main`.
4. أضف متغير البيئة `SEED_PASSWORD` في إعدادات المشروع.
5. اترك `KV_PATH` فارغاً — Deno Deploy يوفّر KV تلقائياً.

النشر التلقائي عبر GitHub Actions مهيّأ في `.github/workflows/deploy.yml`: يفحص الأنواع والتنسيق ويشغّل اختبارات
الواجهات، ثم ينشر عند الدفع إلى `main`. غيّر اسم المشروع في الملف إن اخترت اسماً آخر.

## الأمان

- كلمات المرور بـ PBKDF2-SHA256 بـ120,000 دورة ومِلح لكل حساب، ولا تُخزَّن بأي صورة أخرى.
- الجلسات في ملفات تعريف `HttpOnly` و`SameSite=Strict` و`Secure` على HTTPS، وتنتهي بعد 8 ساعات.
- مقارنة كلمة المرور بزمن ثابت.
- ترويسات `X-Content-Type-Options` و`X-Frame-Options` و`Referrer-Policy` على كل استجابة.
- تنظيف مسارات الملفات الثابتة من محاولات الخروج من المجلد.

### ما يلزم قبل التشغيل الرسمي

- ربط الدخول بالنظام الموحّد للوزارة، وتفعيل مصادقة ثنائية لرؤساء الفرق والحساب الفني.
- نسخ احتياطي دوري لقاعدة KV مع اختبار الاسترجاع.
- مراجعة الالتزام بقانون حماية البيانات الشخصية البحريني، والاستضافة داخل المملكة إن لزم.
- ضبط سياسة الاحتفاظ بسجل التدقيق.
- ربط إدخال المؤشرات التفصيلية (33 للنظامي و25 للمبكر) بشاشة التقييم بدل الإدخال على مستوى المحاور.
