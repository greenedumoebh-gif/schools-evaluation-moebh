# منصة تقييم المؤسسات التعليمية ضمن مبادرة التعليم الأخضر بمملكة البحرين

**الإصدار 1.8.1** — 2026-09-06. الرقم معلن في `/health` وفي `/api/me`، ويظهر في
شاشة الدخول والشريط الجانبي ورأس الطباعة. في شاشة الدخول **يُحقن في الصفحة عند
تقديمها من الخادم** (`{{VERSION}}` في `static/index.html`) فلا يعتمد على نجاح أي
طلب لاحق من المتصفح.

منصة داخلية لتقييم 378 مؤسسة تعليمية على ستة فرق تقييم —
إدارة المنشآت التعليمية، وزارة التربية والتعليم، مملكة البحرين.

## التشغيل محلياً

```bash
SEED_PASSWORD='كلمة-مرور-قوية' KV_PATH=/tmp/kv.db deno task start
```

ثم افتح `http://localhost:8000`. الحسابات: `Z1-1` … `Z4-5` · `PR-1` … `KG-5`
لأعضاء التقييم، `Z1-L` … `KG-L` لرؤساء الفرق، و`TECH` للحساب الفني.
كلمة المرور الابتدائية هي قيمة `SEED_PASSWORD`، ويُطلب تغييرها عند أول دخول.

## الحزم للنشر

```bash
./build.sh     # حزمة النشر + حزمة التسليم، كلاهما باسم يحمل رقم الإصدار
./handoff.sh   # حزمة التسليم وحدها
```

اسم ملف التسليم يحمل رقم الإصدار دائماً. عند أي إصدار جديد: عدّل `version`
و`released` في `data/seed.json` ثم شغّل `build.sh` — لا تُسمِّ الملف يدوياً.

**حزمة التسليم تُحدَّث آلياً مع كل بناء.** `handoff.sh` يشغّل الفحوص الساكنة
وفحص الواجهات وفحص المتصفح، ويرفض إنتاج الحزمة إن سقط أيٌّ منها، ثم يبني
المستند من شيفرة المستودع نفسها فتظل الحزمة مطابقة للإصدار:

- النص السردي في `docs/handoff_body.md` بعناصر بديلة `{{VERSION}}` و`{{DATE}}`
  و`{{API}}` و`{{UI}}` تُملأ بأرقام **مقيسة** لا منقولة.
- ملحق الشيفرة يُجمَّع بمسح المستودع فعلياً، فأي ملف نصي جديد يُلحق تلقائياً.
- الحزم الأقدم تُحذف من مجلد المخرجات حتى لا تلتبس بالحالية.
- `SKIP_TESTS=1` لتخطّي الفحوص، و`API_CHECKS` و`UI_CHECKS` لتمرير عدديهما إن
  شُغّلت الفحوص خارج السكربت.


## الفحص

```bash
deno check main.ts && deno fmt --check && deno lint
BASE=http://127.0.0.1:8000 deno run --allow-net --allow-env tests/api_test.ts
BASE=http://127.0.0.1:8000 python3 tests/ui_check.py     # يتطلب Playwright
```

كلاهما يجب أن ينتهي بـ «النتيجة: كل الفحوص سليمة ✓».

## بنية التقييم

التقييم يقوم على **المؤشرات التفصيلية**: 31 مؤشراً للتعليم النظامي
(سقف 5,400) و25 للتعليم المبكر (سقف 4,500). المقيّم يدخل الأرقام الخام
لكل مؤشر، والخادم يحسب:

- نسبة المؤشر = (البسط ÷ المقام × 100) ÷ المستهدف × 100، بحد أقصى 100%
- المؤشر الوصفي: لم ينفذ 0 · جاري التنفيذ 50 · نفذ 100
- المؤشر ذو القيمة الثانوية: متوسط النسبتين
- نقاط المحور = مجموع (وزن المؤشر × نسبته) · النتيجة = المجموع ÷ السقف
- المسطرة: غير مستدام 0–65 · قيد الاستدامة 66–76 · مستدام جزئياً 77–89 · مستدام 90–100

الحساب كله في الخادم؛ الواجهة تعرض ولا تُعتمد قيمها.

## ملاحظات مفتوحة

- **المؤشر 20 (النظامي)** مستهدفه يتبع المرحلة: 4 للابتدائي و8 للإعدادي
  والثانوي. 48 مؤسسة مصنّفة «متعدد المراحل» أو «ثانوي تخصصي» أو «معهد ديني»
  لا قاعدة لها في الخطة؛ طُبِّق 8 مؤقتاً ويظهر تنبيه في الشاشة.
- **سيادة البيانات:** Deno KV يخزّن ويمرّر البيانات عبر الولايات المتحدة.
  لم يُبتّ في هذا بعد ويجب عرضه على الجهة المختصة قبل إدخال بيانات فعلية.

## المتغيرات البيئية

| المتغير | الوظيفة |
|---|---|
| `SEED_PASSWORD` | كلمة المرور الابتدائية لكل الحسابات (8 محارف فأكثر) |
| `SEED_RESET` | تغيير قيمته يعيد ضبط كلمات المرور مرة واحدة دون المساس بالتقييمات |
| `KV_PATH` | مسار قاعدة Deno KV محلياً |
